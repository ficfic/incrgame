# Contributing

This is a **solo hobby project** (Semantic Drift), built in the open and mostly
through Claude Code. You're welcome to poke around.

- **Issues:** welcome — bugs, ideas, "you got RDF wrong here" especially.
- **Pull requests:** may or may not be merged; it's one person's game. Open an
  issue first if it's substantial.
- **Conventions:** the house rules live in [`CLAUDE.md`](CLAUDE.md) — read it
  before proposing changes. Notably: all player-facing prose is human-written
  (no LLM-generated content), and the game must stay theory-faithful (see
  [`docs/GLOSSARY.md`](docs/GLOSSARY.md)).
- **Design context:** [`docs/GAME_DESIGN.md`](docs/GAME_DESIGN.md) and
  [`docs/DECISIONS.md`](docs/DECISIONS.md) explain what things are and why.
